## 🛡️ Key Security Domain Summaries

### 🔑 Lab 1: Account Security & IAM
* Implemented strict Identity and Access Management (IAM) controls.
* Configured role-based access control (RBAC) and Multi-Factor Authentication (MFA).
* Enforced least privilege policies to eliminate unnecessary permissions across cloud resources.

### 🔒 Lab 2: Secure Isolation & Multitenancy
* Explored logical and physical boundaries within multi-tenant cloud environments.
* Configured isolated workload environments to prevent cross-tenant exposure and resource contention attacks.

### 🔐 Lab 3: Encryption & Key Management
* Configured Key Management Services (KMS) for symmetric and asymmetric encryption key operations.
* Implemented client-side and server-side encryption for cloud storage and databases.
* Verified cryptographic key lifecycle policies, including access delegation and automated key rotation.

### 🌐 Lab 4: Access Control & Network Security
* Configured Virtual Private Cloud (VPC) architectures with public/private subnet segregation.
* Implemented stateful Security Groups and stateless Network Access Control Lists (NACLs) to enforce network perimeter boundaries.
* Configured secure access baselines following Zero Trust principles.

### 📊 Lab 5: Monitoring, Logging & Incident Detection
* Enabled cloud audit logging and stream aggregation for centralized visibility.
* Configured security telemetry alerts for unauthorized API calls, privilege escalations, and unusual network behavior.
* Performed basic incident detection walkthroughs using system logs and security dashboards.
